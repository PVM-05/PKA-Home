# Mô Phỏng Thiết Kế Giao Diện (Wireframe)

Tài liệu này mô tả sơ đồ khối (wireframe) của các màn hình chính bằng cách phác thảo bố cục từ trên xuống dưới.

## 1. Màn hình Đăng nhập (Chung)
```text
+-------------------------------------------------+
|                                                 |
|                 [ Logo Chung Cư ]               |
|            Ứng Dụng Quản Lý Chung Cư            |
|                                                 |
|  [ Thư điện tử (Email)                       ]  |
|  [ Mật khẩu                                  ]  |
|                                                 |
|  ( Nút Đăng nhập )                              |
|                                                 |
|  "Quên mật khẩu? Vui lòng liên hệ Ban quản lý"  |
|                                                 |
+-------------------------------------------------+
```

## 2. Trang chủ Cư dân
```text
+-------------------------------------------------+
| [ Menu ] Xin chào, Nguyễn Văn A   [ Icon Logout]|
|-------------------------------------------------|
| TỔNG QUAN HÓA ĐƠN                               |
| +---------------------------------------------+ |
| | Tổng tiền cần đóng:         1,500,000 VNĐ   | |
| | ( 1 hóa đơn chưa thanh toán )               | |
| | [ Nút: THANH TOÁN NGAY ]                    | |
| +---------------------------------------------+ |
|                                                 |
| THÔNG BÁO MỚI NHẤT                              |
| +---------------------------------------------+ |
| | Cắt nước toàn tòa nhà để bảo trì            | |
| | Kính gửi Quý cư dân, ban quản lý sẽ...      | |
| | 26/08/2026                                  | |
| +---------------------------------------------+ |
| +---------------------------------------------+ |
| | Thu phí quản lý tháng 8                     | |
| | Ban quản lý đã lên hóa đơn phí...           | |
| | 25/08/2026                                  | |
| +---------------------------------------------+ |
|-------------------------------------------------|
| [Trang chủ]  [Hóa đơn]  [Phản ánh]  [Tài khoản] |
+-------------------------------------------------+
```

## 3. Màn hình Gửi Phản Ánh (Cư dân)
```text
+-------------------------------------------------+
| [ < Trở lại ]     Gửi Phản Ánh                  |
|-------------------------------------------------|
| Vui lòng mô tả sự cố hoặc yêu cầu hỗ trợ:       |
|                                                 |
| +---------------------------------------------+ |
| | Ví dụ: Bóng đèn hành lang tầng 5 bị cháy... | |
| |                                             | |
| |                                             | |
| +---------------------------------------------+ |
|                                                 |
| Đính kèm hình ảnh (Tối đa 3 ảnh):               |
| [ + Chọn ảnh từ máy ]                           |
|                                                 |
| [=============================================] |
| [               GỬI YÊU CẦU                   ] |
| [=============================================] |
+-------------------------------------------------+
```

## 4. Trang chủ Ban Quản Lý (Dashboard)
```text
+-------------------------------------------------+
| [ Menu ] Ban Quản Lý              [ Icon Logout]|
|-------------------------------------------------|
| TỔNG QUAN TRẠNG THÁI                            |
| +----------------------+ +--------------------+ |
| | [!] Phản ánh mới     | | [$$] Tổng nợ phí   | |
| |        5             | |      15 Tr         | |
| +----------------------+ +--------------------+ |
| +----------------------+ +--------------------+ |
| | [#] Số căn hộ        | | [v] Đã thanh toán  | |
| |       120            | |      85%           | |
| +----------------------+ +--------------------+ |
|                                                 |
| PHẢN ÁNH CẦN XỬ LÝ GẤP                          |
| - Căn 501: Nước rò rỉ (Đang chờ)                |
| - Căn 704: Mất điện (Đang chờ)                  |
|                                                 |
|-------------------------------------------------|
| [Tổng quan]  [Cư dân]  [Hóa đơn]  [Phản ánh]    |
+-------------------------------------------------+
```
